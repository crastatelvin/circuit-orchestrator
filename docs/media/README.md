# Media Assets

Place project media assets in this folder:

- `demo.gif` - short animated walkthrough shown in root `README.md`
- `demo.mp4` - longer video walkthrough
- `screenshot-builder.png` - workflow builder UI screenshot
- `screenshot-execution.png` - live execution state screenshot

Recommended capture flow:
1. Build a small node graph.
2. Configure at least one AI node.
3. Run workflow and capture wire/node animations.
4. Capture output panel with final result.
